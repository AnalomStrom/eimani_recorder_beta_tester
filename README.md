1. Create a new public GitHub repository and upload `index.html`, `style.css`, `script.js`, `logo.png`, and `README.md` to its root directory.
2. Open the repository on GitHub and click **Settings** in the top navigation bar.
3. Click **Pages** in the left sidebar, then under **Build and deployment**, select **Deploy from a branch** and choose `main` with `/ (root)`.
4. Click **Save** and wait 1–2 minutes for your live site URL (`https://<username>.github.io/<repo-name>/`) to appear at the top of the Pages settings.
